# Access utilities

We've made a set of utilities to help you access the data stored on Source Cooperative, even if you don't have expertise in python, {term}`Zarr` files, or working in the cloud. The utilities are all housed in the
[srm-downscaling-data-utils](https://github.com/carbonplan/srm-downscaling-data-utils) repository.
Follow the instructions in that repository's
[README](https://github.com/carbonplan/srm-downscaling-data-utils/blob/main/README.md) to learn how
to install and use the utilities.

| What do you want to do? | Use |
| --- | --- |
| Inspect the data interactively in a Jupyter notebook | [`notebooks/subsetting-and-exporting.ipynb`](https://github.com/carbonplan/srm-downscaling-data-utils/blob/main/notebooks/subsetting-and-exporting.ipynb) |
| Download a subset of the data with Python | [`scripts/download.py`](https://github.com/carbonplan/srm-downscaling-data-utils/blob/main/scripts/download.py) |
| Download a subset of the data with Bash | [`scripts/download.sh`](https://github.com/carbonplan/srm-downscaling-data-utils/blob/main/scripts/download.sh) |
| Explore the input data in a Jupyter notebook | [`notebooks/input-data.ipynb`](https://github.com/carbonplan/srm-downscaling-data-utils/blob/main/notebooks/input-data.ipynb) |
